# Flow Launcher Toolset

This repository contains the Flow Launcher plugin folders:

- `TextTools`
- `rasmio_tool`

## Install

1. Clone this repository.
2. Open the cloned folder.
3. Run `install.cmd`.

The installer copies both folders into:

`C:\Users\{username}\AppData\Roaming\FlowLauncher\Plugins`

After installation finishes, the cloned repository folder and the installer file are removed automatically.

## Notes

- Run the installer from the repository root.
- If you want to keep a local copy, back it up before running the installer.
